隱私政策

TraderMap 在 iOS、iPadOS 和 tvOS 上處理資訊的方式。

01

適用範圍

本政策適用於 iOS/iPadOS 版 TraderMap（Bundle ID：com.17class.TraderMap）、tvOS 版 TraderMapTV（Bundle ID：com.17class.TraderMapTV）以及本技術支援網站。兩個 App 採用相同的資料處理方式。

02

我們不要求提供的資料

TraderMap 無需註冊帳戶，也不會要求提供姓名、電子郵件、電話號碼、郵寄地址、付款資訊、錢包地址、助記詞或私鑰。App 不包含廣告 SDK、第三方分析 SDK 或跨 App 追蹤技術。

03

僅儲存在裝置上的資訊

為儲存設定和最近瀏覽內容，App 會在裝置本機儲存以下資訊。這些資訊不會作為使用者輪廓上傳。

  • 語言、提示音和音量設定
  • 所選幣種、提醒門檻和圖表收藏
  • 僅供開發環境預測資料連線使用的隨機 App 級識別碼
  • 短期快取的市場和內容回應
04

網路處理

為提供即時資訊，App 會連線至已設定的 TraderMap 閘道以及市場/內容供應商。如同任何網路服務，連線必然會揭露 IP 位址，並可能處理請求時間、App User-Agent、所選語言、請求介面和市場篩選條件。目前 TraderMap 閘道只在記憶體中短暫使用 IP 位址進行流量限制，不會據此建立使用者輪廓。

基礎設施服務商可能依其條款處理有限的連線日誌，用於傳輸、可靠性和安全。開啟新聞原文後，將適用該發布者的隱私政策。本站由 GitHub Pages 託管，因此 GitHub 可能依其隱私聲明處理標準網頁請求資訊。

05

使用目的與分享

資訊僅用於提供所請求的市場內容、儲存本機偏好、保護服務可用性、診斷故障和履行法律義務。TraderMap 不出售個人資訊，也不會為定向廣告分享資訊。服務商只能在營運所需範圍處理資訊，並須提供符合本政策及適用法律的保護。

06

保留期限與您的選擇

本機偏好會保留到您修改、重設相關設定或刪除 App。快取為暫存資料，可由 App 或作業系統清理。參考閘道中的流量限制記錄約 60 秒後失效。刪除 App 或中斷其網路即可停止 App 的網路處理。

  • 刪除 App 以移除本機 App 資料
  • 在 App 內變更語言、篩選、收藏及聲音設定
  • 若您認為服務持有您的資訊，或希望行使法定隱私權，請聯絡技術支援
07

兒童、跨境處理與安全

TraderMap 是面向一般使用者的市場資訊產品，並非面向兒童。網路服務商可能在您所在國家或地區之外處理資訊。正式環境使用 HTTPS/WSS 並採取合理保護措施，但任何網路傳輸都無法保證絕對安全。

08

政策變更與聯絡

當 App 功能、服務商或法律發生變化時，我們可能更新本政策。頁面頂部的生效日期代表目前版本。隱私問題和請求可透過官方技術支援管道提交。

僅提供市場資訊——不構成投資建議，也不提供訂單執行服務。
