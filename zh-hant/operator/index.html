01

開發者與營運者

TraderMap 和 TraderMapTV 以 17ClassDeveloper 名義開發和營運，對應 GitHub 帳號為 17classdeveloper-design。

  • iOS/iPadOS：TraderMap — com.17class.TraderMap
  • tvOS：TraderMapTV — com.17class.TraderMapTV
02

服務範圍

兩款 App 都是唯讀市場資訊用戶端。營運者不提供經紀服務、錢包連接、資產託管、儲值、提領或訂單執行。

03

官方管道

本站及下方程式碼儲存庫為官方公開資訊和支援管道。如法律要求，App Store 商店頁面會顯示 Apple 管理的銷售者和交易者狀態資訊。

04

智慧財產

TraderMap 軟體、介面和原創資料受適用智慧財產法保護。第三方市場資料、文章內容、名稱和商標歸各自權利人所有，並在相應授權範圍內使用。
