01

問題を報告する前に

TraderMapにはiOS/iPadOS 16以降またはtvOS 16以降と、ライブデータ用のインターネット接続が必要です。市場データが遅延・停止する場合があります。

  • ネット接続を確認
  • アプリを終了して再起動
  • 別の銘柄・ページを試す
  • アプリとOSを最新版にする
02

報告に含める情報

GitHub Issueを作成し、TraderMap（iOS/iPadOS）またはTraderMapTV（tvOS）を明記してください。アプリ版、端末、OS版、言語、再現手順、必要に応じて画面画像を含めてください。

  • 画像から個人・機密情報を削除
  • パスワード、APIトークン、シードフレーズ、秘密鍵を投稿しない
  • 非公開の取引・財務記録を投稿しない
03
