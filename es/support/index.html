01

Antes de informar de un problema

TraderMap requiere iOS/iPadOS 16 o posterior, o tvOS 16 o posterior, además de conexión a internet para los datos en tiempo real. Las fuentes de mercado pueden sufrir retrasos o no estar disponibles ocasionalmente.

  • Confirme que el dispositivo está conectado
  • Cierre TraderMap y vuelva a abrirlo
  • Pruebe otro símbolo o página
  • Confirme que la app y el sistema operativo están actualizados
02

Qué debe incluir

Abra una incidencia en GitHub e identifique el producto: TraderMap (iOS/iPadOS) o TraderMapTV (tvOS). Incluya la versión de la app, el modelo del dispositivo, la versión del sistema operativo, el idioma seleccionado, los pasos para reproducir el problema y capturas de pantalla si resultan útiles.

  • Elimine la información personal o confidencial de las capturas
  • Nunca publique contraseñas, tokens de API, frases semilla o claves privadas
  • No publique registros privados de operaciones o finanzas
03

Canal de contacto

El soporte técnico, los comentarios generales y las solicitudes de funciones se gestionan mediante el registro público de incidencias del repositorio. El operador es 17ClassDeveloper (cuenta de GitHub: 17classdeveloper-design). No se garantizan los tiempos de respuesta.
