01

문제 신고 전 확인

TraderMap은 iOS/iPadOS 16 이상 또는 tvOS 16 이상과 실시간 데이터용 인터넷 연결이 필요합니다. 시장 소스가 지연되거나 일시 중단될 수 있습니다.

  • 인터넷 연결 확인
  • 앱 종료 후 다시 실행
  • 다른 종목이나 페이지 확인
  • 앱과 운영체제를 최신 버전으로 업데이트
02

신고에 포함할 내용

GitHub 이슈를 열고 TraderMap(iOS/iPadOS) 또는 TraderMapTV(tvOS)를 명시해 주세요. 앱 버전, 기기 모델, OS 버전, 선택 언어, 재현 절차와 필요한 스크린샷을 포함해 주세요.

  • 스크린샷에서 개인정보와 기밀정보 삭제
  • 비밀번호, API 토큰, 시드 문구 또는 개인 키를 게시하지 않기
  • 비공개 거래·금융 기록을 게시하지 않기
