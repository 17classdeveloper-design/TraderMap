隐私政策

TraderMap 在 iOS、iPadOS 和 tvOS 上处理信息的方式。

生效日期: 2026-07-22iOS/iPadOS 版 TraderMap（com.17class.TraderMap）及 tvOS 版 TraderMapTV（com.17class.TraderMapTV）
01

适用范围

本政策适用于 iOS/iPadOS 版 TraderMap（Bundle ID：com.17class.TraderMap）、tvOS 版 TraderMapTV（Bundle ID：com.17class.TraderMapTV）以及本技术支持网站。两个 App 采用相同的数据处理方式。

02

我们不要求提供的数据

TraderMap 无需注册账户，也不会要求提供姓名、电子邮箱、电话号码、邮寄地址、支付信息、钱包地址、助记词或私钥。App 不包含广告 SDK、第三方分析 SDK 或跨 App 跟踪技术。

03

仅保存在设备上的信息

为保存设置和最近浏览内容，App 会在设备本地保存以下信息。这些信息不会作为用户画像上传。

  • 语言、提示音和音量设置
  • 所选币种、提醒阈值和图表收藏
  • 仅供开发环境预测数据连接使用的随机 App 级标识符
  • 短期缓存的市场和内容响应
04

网络处理

为提供实时信息，App 会连接已配置的 TraderMap 网关以及市场/内容提供商。与任何互联网服务一样，连接必然会暴露 IP 地址，并可能处理请求时间、App User-Agent、所选语言、请求接口和市场筛选条件。当前 TraderMap 网关只在内存中短暂使用 IP 地址进行限流，不会据此建立用户画像。

基础设施服务商可能依据其条款处理有限的连接日志，用于传输、可靠性和安全。打开新闻原文后，将适用对应发布者的隐私政策。本站由 GitHub Pages 托管，因此 GitHub 可能根据其隐私声明处理标准网页请求信息。

05

使用目的与共享

信息仅用于提供所请求的市场内容、保存本地偏好、保护服务可用性、诊断故障和履行法律义务。TraderMap 不出售个人信息，也不会为定向广告共享信息。服务商只能在运营所需范围内处理信息，并须提供符合本政策及适用法律的保护。

06

保留期限与您的选择

本地偏好会保留到您修改、重置相关设置或删除 App。缓存为临时数据，可由 App 或操作系统清理。参考网关中的限流记录约 60 秒后失效。删除 App 或断开其网络即可停止 App 的网络处理。

  • 删除 App 以移除本地 App 数据
  • 在 App 内更改语言、筛选、收藏及声音设置
  • 如果您认为服务持有您的信息，或希望行使法定隐私权，请联系技术支持
07

儿童、跨境处理与安全

TraderMap 是面向一般用户的市场信息产品，并非面向儿童。网络服务商可能在您所在国家或地区之外处理信息。生产环境使用 HTTPS/WSS 并采取合理保护措施，但任何互联网传输都无法保证绝对安全。

08

政策变更与联系

当 App 功能、服务商或法律发生变化时，我们可能更新本政策。页面顶部的生效日期代表当前版本。隐私问题和请求可通过官方技术支持渠道提交。

仅提供市场信息——不构成投资建议，也不提供订单执行服务。
